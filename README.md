### About
**Przecinek is a minimal graphics and audio library** being made in C. It's purpose is to make it easier to create window apps for beginner programers while keeping their project small-sized. Przecinek uses only system build-in libraries. It's well documented and it's being actively improved and extended.
> [!NOTE]
> Remember that this project started not a long time ago and still does not have good amount of features in it :-PP

## Assets
Przecinek uses two libraries:
- For Windows version [WinAPI](https://github.com/microsoft/Windows-classic-samples) is being used,
- for Linux(X11) version [X11Lib](https://gitlab.freedesktop.org/xorg/lib/libx11) is being used.
